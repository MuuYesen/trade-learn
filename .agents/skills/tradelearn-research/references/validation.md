# 检验方法：前视、切分、显著性、参数曲面、扣除搜索

回测里最常见的错误不是代码写错，而是**在同一份数据上既选参数又评价参数**，以及**把运气当成能力**。这一页给出第 3–5 步的统计做法和公式；判读线统一在 `gates.md`，验证流程本身的自检在 `self-check.md`，行情、运气、脆弱性检查在 `robustness.md`。

TradeLearn 提供切分工具；统计检验用 numpy / scipy 自己算即可，算完把中间量（N、T、偏度、峰度、带宽等）写进报告，便于复核。

## 一、前视偏差

**规则**
- 滚动、扩展统计只用到当根之前：`rolling(...).mean().shift(1)` 这类写法；全样本的均值、标准差、分位数都是未来信息。不用居中窗口（`center=True`）。
- 标准化、去极值、特征选择、模型拟合、阈值确定，**只在训练段拟合**，再原样应用到测试段。不要对全样本 `fit_transform`。只用特征之间关系、不碰目标的步骤（删列、类型转换、按特征间相关剔除共线）可以在切分前做。
- 时间序列不能打乱：交叉验证不用 `shuffle=True` 的 k 折。
- 标签按"收盘到收盘"算、成交却在下一根开盘，这个差距就是隐藏的前视。标签要和实际成交时点一致。
- 基本面、宏观数据按**发布日期**对齐，不按报告期；每个特征有自己的可用时间（`data-audit.md` 第四节）。
- A 股前复权的历史价格包含了后来的除权信息，涉及绝对价位的规则要用不复权价。
- **高周期指标贴到低周期上**：先把高周期序列后移一个周期再向前填充，只用已收完的高周期 bar。写明是"在高周期网格上算 20 期"还是"在阶梯化的低周期序列上算 20 根"——两者都能运行，却是两个不同的策略。
- **同一根 bar 内止损和止盈都被触及**：只有 OHLC 时按不利的一方（先止损）处理；再按有利顺序跑一次，差别大说明结论取决于数据分辨率，要换更细的数据或逐事件引擎。

**怎么查**（完整做法见 `self-check.md`）
- **截断重算**：把原始数据截到某个日期，从头重跑整条流程，截断点之前的**仓位**必须和完整数据算出的完全一致。
- **从持仓重建收益**：`收益[t+1] = 持仓[t] × 标的收益[t+1] − 成本 × |持仓[t] − 持仓[t−1]|`，和引擎报告的收益对得上。
- **延迟一根**：把成交整体推后一根 bar。收益大幅消失，说明策略对时点极其敏感，要确认不是用到了当根价格。
- **好得不像真的**：日频简单策略夏普超过 2；样本内外几乎一样好（差距不到 5%）；胜率超过 90% 而回撤很小——先当作泄漏或 bug 排查。

## 二、切分

- **训练段**：选参数、拟合模型、调规则、建成本模型、排查 bug。
- **测试段**：只在下结论时**看一次**。看完不满意再改，就需要一段新的测试区间。测试段怎么登记、哪些行为会悄悄用掉它，见 `experiment-log.md` 第二节。
- 测试段一般取总长度的 20%–30%，并覆盖一种以上的行情。训练段要足够支撑网格规模：两年日线（约 500 个观测）上扫几十万组参数，等于用 500 个数据点拟合几十万个参数。
- 可选：在训练段和测试段之间再留一段**验证段**，专门做区域或模型选择，让测试段只做最终评估。研究按四个阶段走：发现（想法和诊断）→ 选择（只用训练、验证段）→ 确认（测试段只评一次）→ 监控（模拟盘或实盘对照事先写下的预期）。

```python
from tradelearn.research import time_split

train, test = time_split(bars, split="2023-01-01")   # train < 切分点，test >= 切分点
```

**按信息区间剔除**。每个样本的信息区间 = [最早用到的输入时间（特征回看的起点）, 确定标签所需的最后时间]。训练样本的信息区间只要和任一测试样本重叠，就剔除。用"未来 20 天收益"做标签时，切分点前 20 天内的训练样本，其标签已经伸进了测试段：

```python
from tradelearn.research.temporal import forward_return, purged_splits

labels = forward_return(bars, horizon=20)            # 每行未来 20 个观测的收益，列为 forward_return、label_end
parts = purged_splits(labels, train_end="2023-01-01", validation_end="2024-01-01")
# 返回 {"train", "validation", "test"} 三组索引；不给 validation_end 时只有 train、test
# 只保留标签在下一段开始前就已结束的样本
```

**输入要求**（不满足直接报错，不会替你修）：
- `bars` 和 `labels` 都以 `MultiIndex(timestamp, symbol)` 为索引，索引名正好是这两个；
- 时间戳带时区且为 UTC；行唯一，并按索引升序排好；
- `labels` 必须有 `forward_return` 与 `label_end` 两列，`label_end` 晚于信号时间戳；
- **单标的数据也要做成这种格式**（symbol 层只有一个值）。

`forward_return(bars, horizon=..., unit="observations" | "seconds", price="close")`：`unit="seconds"` 时要求 t+h 恰好有观测，否则留空。它是预测用的价格标签，不是可成交的交易收益。

`purged_splits` 按标签结束时间剔除；特征回看很长时，再按回看起点检查一遍重叠。

**间隔（embargo）**：剔除之外，在每个连续测试块**之后**再留一段间隔，吸收残留的序列相关。长度**按特征和收益的自相关衰减到不显著所需的期数确定**（例如自相关首次落入 ±2/√N 以内的滞后），**至少覆盖标签跨度**。按交易日计数，不按自然日或行号。报告里写明取值和依据。

- 只用过去数据训练的滚动验证，在测试块**之前**留的空档是另一件事，和 embargo 分开报告。
- 多标的面板：同一交易日的所有标的整体放在训练侧或测试侧，不能把同一天拆到两边。
- 按完整信息区间剔除后，embargo 可能没有再多剔除任何样本。这时写"间隔已执行，无增量剔除"，**不要为了让间隔显得有用而缩窄信息区间**。
- 输入必须先按时间排序；顺序不对就报错，不悄悄重排。

## 三、有效观测数与显著性

**交易笔数不是信息量。** 在一个构造为零收益、16 个相关标的、持仓 20 天的模拟里，2016 笔交易只相当于约 237 个独立观测，按交易笔数做的 t 检验在名义 5% 的水平下有近一半误报为显著。

- 显著性按**时间段收益**（日收益或策略的自然周期）计算，交易再多也造不出更多的天数。
- **自相关修正**：`N_eff = N / (1 + 2 Σ_k (1 − k/N) ρ_k)`，ρ_k 为 k 阶自相关；最大滞后取 `min(N/4, 4·(N/100)^(2/9) + 10)`，分母 ≤ 0 时退回 N。
- **重叠标签**：持有 H 期、每期采样，独立观测约为 `N / H`。1000 个日度样本、20 天持有期，只有约 50 个独立点。
- **持仓重叠的交易**（只有交易列表时）：交易 i、j 的相关近似为 `ρ_ij = 重叠持仓时长 / sqrt(时长_i × 时长_j) × 标的间相关`（同一标的取 1，截到 [0,1]，对角为 1），有效笔数 `N_eff = N² / Σ_ij ρ_ij`。报告写成"2016 笔交易，约 237 个有效观测"。
- **截面相关**：N 个标的、平均两两相关 ρ̄ 时，独立赌注数约 `N / (1 + (N − 1)·ρ̄)`。10 个标的、ρ̄ = 0.6，约 1.5 个。压力期相关更高时，用只取下跌日算出的相关。
- **两种口径都报，取更保守的**：
  - HAC：长期方差 `S = γ0 + 2 Σ_{k=1..L} (1 − k/(L+1)) γ_k`（Bartlett 核），带宽 L 取持有期或信号回看期，拿不准时用 `floor(4·(n/100)^(2/9))`。报方差膨胀因子 `S/γ0`，t 值用 Newey-West 标准误。
  - 按下注：把仓位不变的最长连续区间当作一笔下注，每段合成一个收益，在这些值上算夏普和 t。仓位粘、日收益近似独立的策略，日度 HAC 修正很小，这一口径才看得出问题。
- **夏普的标准误**：按每期数据算，每期夏普 ŝ、n 期观测时 `SE(ŝ) ≈ sqrt((1 + ŝ²/2) / n)`，年化时乘 √q（q 为每年期数，日频 252）。等价写法 `SE(S_年化) ≈ sqrt((1 + S²/(2q)) / T_年)`。例：4 年日频、年化夏普 1.0，SE ≈ 0.50；半年、夏普 0.8，SE ≈ 1.41。实现和验算见 [标准误自检](self-check.md#八回测出数前的两项自检)。收益自相关严重时，n 换成有效观测数 N_eff。置信区间包含 0，就是"没有显著的净收益"。
- **在哪段数据上算**：这个置信区间和第五节的紧缩夏普，在**拼接后的全部滚动验证样本外结果**上算（第九节）；单独的最终测试段太短，只用来看衰减和证伪条件。
- **序列相关下的年化（Lo）**：`S_年化 = η(q) × S_每期`，`η(q) = q / sqrt(q + 2 Σ_{k=1}^{q−1} (q − k) ρ_k)`，日频 q = 252；ρ_k 只估 k ≤ 10，在 1%/99% 分位截尾后的收益上估，k > 10 取 0。有陈旧价格、平滑估值、慢调仓时，直接乘 √252 会高估夏普。
- **比例类指标带区间**：胜率等用 Wilson 区间，`中心 = (p̂ + z²/2n) / (1 + z²/n)`，`半宽 = z·sqrt(p̂(1 − p̂)/n + z²/4n²) / (1 + z²/n)`，z = 1.96。100 笔交易的胜率误差约 ±10 个百分点。
- **相关系数带区间**：`z = artanh(r)`，`SE = 1/sqrt(n − 3)`，`z ± 1.96·SE` 换回 r。5% 水平下最小可检出的 |r|：n = 30 约 0.36，n = 100 约 0.20，n = 252 约 0.12。不同频率的相关不能直接比：频率越高，相关往往越低。

## 四、参数曲面与稳定区域

1. **网格**：选承载假设的 1–3 个参数轴；范围放宽到能看见表现下降的边缘。时间周期、指标变体这类离散选择也作为一个轴一起扫、一起平滑、一起计数，不拆成互不相关的"独立研究"。机制不依赖的参数不扫。
2. **扫描并记录**：每个组合都计入尝试次数。扫完任取一格单独再跑一次，和网格里那格的值核对——参数枚举顺序与轴顺序错位时，热力图会被静默转置。
3. **平滑**：二维网格取每格与周围 3×3 的平均，一维取相邻几格的平均。
4. **找区域**：保留平滑后指标在 `最优值 − 1 个标准误` 以内的全部组合。这个标准误是**最优格子平滑后指标**的标准误，用该格子的样本长度按第三节公式计算。
5. **区域体检**，逐项写进报告：
   - 覆盖率 = 区域格数 / 有效格数；连通分量数（二维按上下左右相邻计）。
   - 只有 1–3 格：没有高原，到此为止。整张网格都在区域内：网格太窄，或这个参数不影响结果，两种都写明。
   - 区域贴着网格边界：真实区域延伸到网格外，放宽网格重跑，重跑计入尝试数。最多放宽重跑 2 次；仍贴边就记录"区域无界"作为发现，不再继续。
   - 两块分离的高原：可能是两种行情或两种机制，分别研究，**不跨高原取平均**。相邻格差异极大：步长太大或策略不稳定，都算发现。
6. **验证区域不是巧合**：在区域内，比较各组合样本内排名与样本外表现的秩相关。通常接近 0——这说明按样本内排名挑选，挑的是噪声。**明显为正时先查泄漏**，不要据此在区域里继续挑。
7. **取整体**：每个时点持有区域内各组合目标仓位的**算术平均**，等权，不按样本内夏普加权（加权会把刚去掉的挑选重新引入）。合并后的仓位单独检查换手、单次最大仓位和容量：平均后常变成更频繁、更小步的调整，要在成本模型下重新确认。
8. **对照**：报告里放一张两行的表——样本内最优格的样本外表现，和合并区域的样本外表现，各带标准误。

画参数热力图放进报告。夏普、最大回撤各画一张：夏普最高但回撤翻倍的区域不算稳健。至少两个参数**同时**变，不只做一次一个参数的扫描。

**曲面本身能不能用**
- **稳健比例**：整张网格里扣成本夏普 > 0 的组合占比。
- **断崖**：沿每个轴排序，相邻格指标差的绝对值超过"相邻差值序列标准差的 2 倍"，标为断崖，说明在拟合一条边界。
- **自由度**：数参数时，每个指标周期、每个数值阈值、显式的仓位比例、止损和止盈距离各算 1 个；手续费、滑点、信号延迟不算。参数 ≤ 4 理想，5–6 可接受，≥ 7 标记过度优化；入场条件加过滤条件超过 10 个要警示。精确到小数的阈值（RSI > 33.5）多半是拟合痕迹，优先用整数或常用的半步值。
- **快速扰动**：做完整曲面之前，止损取基准的 50%–150%、止盈取 80%–120%、日内进出场时间偏移 ±15–30 分钟，先看是否只在一个精确值上成立。

**经验警戒线**
- 只在某个精确值上有效（止损 2.13% 有效，2% 和 2.5% 都不行）。
- 换一个时间段，最优参数或区域位置大幅漂移，或需要频繁重新优化。
- 样本外表现不到样本内的一半。
- 最优的格子恰好都是换手最高的：先怀疑成本低估。
- 样本外日均换手明显高于样本内（例如 2 倍以上）：参数只适配了样本内的行情。

## 五、扣除尝试次数：紧缩夏普与多重检验

在 N 次尝试中取最好的一次，即使每次都没有真实收益，最大夏普的期望也明显大于 0。紧缩夏普估计"考虑了尝试次数、样本长度和收益分布形状后，这个夏普仍大于零的概率"。

设：`ŝ` 为所选策略的**每期**夏普（未年化），`T` 为观测期数，`γ3` 为收益偏度，`γ4` 为峰度（正态为 3），`N` 为尝试次数，`V` 为各次尝试每期夏普的方差，`Φ` 为标准正态分布函数。

```
概率夏普（相对目标 s*，通常取 0）：
PSR(s*) = Φ( (ŝ − s*) × sqrt(T − 1) / sqrt(1 − γ3·ŝ + (γ4 − 1)/4 · ŝ²) )

在没有真实收益时，N 次尝试的最大夏普期望约为：
s0 = sqrt(V) × ((1 − 0.5772) × Φ⁻¹(1 − 1/N) + 0.5772 × Φ⁻¹(1 − 1/(N·e)))

紧缩夏普：DSR = PSR(s0)
```

- 报告里**原始夏普和紧缩夏普并列**，写明 N。ŝ 用**每期**夏普，不要代入年化值。
- 计入的尝试次数只是研究者真实自由度的下限，所以 DSR 是偏乐观的上界。
- `V` 从所有**配置**的收益矩阵里估（不是同一配置的多条 CPCV 路径，路径之间高度相关）；只有被选中的那一条时只能粗估，结果偏宽松，要说明。

**N 怎么取**
- 报告的是网格里的最大值：N = 网格格数（相邻格相关，偏保守，方向正确）。
- 报告的是合并区域（平均，不是最大）：区域本身是在整张网格上搜出来的，**两种都报**——按独立挑选次数（通常是 1 或对比过的方案数）扣的值，和按网格大小扣的保守值。
- 量级比精确更重要：少于约 100 次，挑选偏差有限；约 10⁴ 次时，3.5–4 年日频样本下纯噪声的最大年化夏普约 1.9–2.1。
- 快速核对：`E[max] ≈ SE × ((1 − γ)·Φ⁻¹(1 − 1/N) + γ·Φ⁻¹(1 − 1/(N·e)))`，γ = 0.5772，SE 用纯噪声（S = 0）的年化标准误 `sqrt(1 / T_年)`；紧缩值 = S − E[max]，紧缩值 > 0 且紧缩值 / SE > 1.645（单侧 95%，与 `gates.md` 的 DSR ≥ 0.95 一致）才算存活。约 3.5 年（SE ≈ 0.53）时，N = 100 的 E[max] 约 1.34，N = 10⁴ 约 2.05；4 年（SE = 0.50）时分别约 1.27、1.93。

**最短样本长度（MinTRL）**：这个夏普要有多少期观测才在置信水平 1−α 下显著大于 s*：

```
MinTRL = 1 + (1 − γ3·ŝ + (γ4 − 1)/4 · ŝ²) × (Φ⁻¹(1 − α) / (ŝ − s*))²
```

- 只在 ŝ > s*（通常 ŝ > 0）时计算。ŝ ≤ 0 时公式没有意义：结论是"没有显著的净收益"（未证实），不是"再加数据"。
- ŝ > 0 但实际样本 T 小于 MinTRL：证据不足，需要更长的样本，不是策略不行。

**最短回测年数（MinBTL）**：尝试了 N 次时，样本年数至少约 `2·ln N / S_年化²`，否则纯噪声也容易挑出这个夏普。

**多重检验折扣（Harvey-Liu）**：把年化夏普换成 t 值（约为 `S × sqrt(年数)`）和 p 值，按 N 用 Bonferroni（p × N）、Holm 或 BHY 调整，再换回夏普，得到"打折后的夏普"。打折后为负或接近 0，说明没有统计证据。t > 3 是候选数很多时（例如 N ≥ 100）才用的严格线；平常不过只作警示，不作核心项。

## 六、联合检验：Reality Check 与大规模规则筛选

**White Reality Check / Hansen SPA**：回答"如果全都没本事，试过的这些里最好的那个，有多常见能这么好"。DSR 只用尝试次数和夏普方差做近似，这个检验直接用全部候选的联合分布。

1. 候选集 = 在这份数据上试过的**所有**配置的逐期净收益（相对基准的差 d_k），包括被选中的那个，从尝试台账取。漏放会让检验变宽松，必须漏放时写明。
2. 统计量 `T_sys = sqrt(n) × d̄_sys / ω̂_sys`。
3. 平稳自助法（平均块长约 20 天，B = 1000），**所有候选抽同一批日期**，保留它们之间的相关。
4. 每次重抽 `T*_b = max_k sqrt(n) × (d̄*_{k,b} − g(d̄_k)) / ω̂_k`。Hansen 再中心化：`g(x) = x × 1{x ≥ −ω̂_k × sqrt(2 ln ln n / n)}`，明显差的候选不抬高零分布。重抽的最大值要和**中心化后**的零分布比，不能和 0 比。
5. `p = (1 + #{T*_b ≥ T_sys}) / (B + 1)`。

**成千上万条规则里挑选**（候选 ≥ 20 且高度相关时）：
1. 对同一族候选算 z 值；经验零分布 `μ0 = z 的中位数`，`σ0 = 四分位距 / 1.349`（假设绝大多数候选是零效应）。
2. 每个候选的预期误选数 `EFP_i = N × 2 × (1 − Φ(|z_i − μ0| / σ0))`，只选 EFP_i < α 的（默认 α = 0.3）。每个规则族单独做、单独给预算。
3. 不用 BH/FDR 选：一个真效应会点亮几百个相关的"亲戚"，FDR 随之放宽。
- 重抽样方法按依赖结构选：时间上的序列相关用块自助或平稳自助；截面相关强时按日期整体重抽，不按"标的 × 日"重抽，否则区间会窄得离谱。

## 七、回测过拟合概率（PBO）

适用于比较了很多组参数或变体时。做法（组合对称交叉验证，CSCV）：

1. 把整段时间切成 S 个等长的块（例如 S = 16，取偶数），所有候选组合在每块上都有收益。
2. 枚举所有"取一半块作样本内、另一半作样本外"的组合；太多时均匀抽约 500 种。
3. 每一种划分下，**用实际要用的挑选流程**（平滑 → 一个标准误内的区域 → 等权合并）选出样本内的结果，看它在样本外的排名百分位 ω。对一个你不会使用的"取最大"流程算 PBO，回答的是错的问题。
4. PBO = 样本内选出者在样本外**低于中位数**的划分所占比例。同时报告样本外相对排名 logit 的中位数。

判读：
- 判读线见 `gates.md`。纯噪声上"取最大"流程的 PBO 约 0.5：候选之间没有真实差异时，样本内选出者在样本外的排名是随机的。明显高于 0.5，说明样本内最好的在样本外系统性变差（例如表现会反转）。
- PBO 是选择失败的概率，不是 p 值，不能套"小于 0.05"。它是过拟合程度的下界（真实自由度多于申报的）。
- 对划分做自助重抽可以给近似区间，但划分彼此重叠，区间偏窄，要注明。
- 候选组合少于约 10 个时 PBO 意义不大。

## 八、组合净化交叉验证（CPCV）

滚动验证只给一条历史路径，一条路径可能是运气。CPCV 给出多条。

1. 把交易日按时间分成 N 个连续组，每次取 k 组作测试，共 C(N,k) 种划分。默认 N = 6、k = 2（15 种划分）；N = 8、k = 2（28 种）为常用；样本多时可用 N = 10。
2. 每个训练与测试的边界（包括中间的边界）都按信息区间剔除；每个连续测试块之后加间隔，相邻的测试组合并成一个块。多标的面板按标的分别剔除，同一交易日不拆开。
3. 把样本外结果拼成 `C(N−1, k−1)` 条完整路径（等于 `k/N × C(N,k)`；N = 6、k = 2 时 5 条，N = 10、k = 2 时 9 条），每条路径恰好覆盖每个时间组一次。注意路径数不是划分数。
4. 剔除后训练集应保留 ≥ 60% 的样本，否则减少 k 或缩短间隔并说明。
5. 报告每条路径的夏普，以及中位数、P10、最差值、四分位距、亏损路径占比。**不只报最好的一条，也不只报平均。**

判读：CPCV 用到了测试段前后的数据，它是"历史稳健性"证据，不能替代只用过去数据的滚动验证，两者并列。PBO 用的 CSCV 是另一套对称切分，不能把 CPCV 的路径矩阵直接拿来算 PBO。

## 九、滚动验证

单次切分只验证了一个时间段。

- **滚动窗口**：训练窗口固定长度、向前滑动，适合旧数据参考价值下降的市场（如加密货币）。**扩展窗口**：起点固定、终点延伸，适合数据较少或行情较稳定时。条件允许时两种都跑，结果明显分歧说明数据不平稳。
- **每一折都重做参数选择流程**（第四节的区域选择），向前带的是区域整体。每折重新挑最优点，验证的是一个你不会使用的流程，结果会偏好；引擎自带的"每折取最大"版本只能作为要超过的基线。
- **结构下限**：折数尽量 ≥ 5，每折有效观测尽量 ≥ 30，测试窗长于标签跨度的 2 倍；测试窗首尾相接、互不重叠。达不到时，结论最高到"证据不足"。
- **每折训练量下限**事先定（例如 ≥ 252 个交易日；多标的再加最少标的数）。任何一折不满足、拟合失败或覆盖不全，不跳过这一折、不用部分结果、不用 NaN 填充：把它列为证据缺口，结论最高到"证据不足"；失败原因是流程本身出错时，按 `gates.md` 第一节判"无法判断"。悄悄跳过的往往正是最难的行情段。
- **预热**：每折测试段的指标用测试段之前的数据补足，不让测试段开头在指标未成形时交易。
- **每折记录**：选出的区域位置（例如区域重心）、样本外与样本内之比（WFE）、所处行情。区域位置稳定是机制稳定的证据；来回跳是拟合的证据。WFE 是两个噪声数之比，看趋势不看单个值。每个训练窗至少覆盖 2 种行情，训练与测试同属一种行情的折要标出来。
- **三层分开记**：模型层（误差）、信号层（IC、换手）、策略层（扣成本夏普）。三层走向不一致，问题出在"翻译"：模型好但 IC 差，标签或目标不对；IC 好但策略差，组合构建、成本或换手有问题。
- **选择的代价**：每个窗口里事后表现最好的候选是"事后最优"。选择遗憾 = 事后最优的夏普 − 选中候选的夏普，对各窗口取平均；选择乐观差 = 全样本最优的夏普 − 滚动选择拼接出的夏普。后者说明"全样本挑最优"报出来的夏普有多少是拿不到的。
- 把每一折的样本外结果拼接成一条曲线来看，不只看一个总数。各折差异很大，说明依赖特定行情。**显著性检查（第三节的置信区间、第五节的紧缩夏普）在这条拼接曲线上做**。
- **最终测试段**（滚动验证之后另留、只用一次的一段）不再做显著性检验，只做两件事：
  - 看相对交叉验证（或滚动验证）的**衰减** = 1 − 测试段指标 / 交叉验证指标（指标同口径，例如扣成本夏普）。≤ 30% 通过；< 5% 好得可疑，先查泄漏；交叉验证指标 ≤ 0 时比值无意义，不算衰减。
  - 看是否触发第 1 步写下的证伪条件；触发即"未证实"。
- 比较不同验证方式时，先取它们都打过分的那部分样本做主比较（滚动验证覆盖的样本通常更少）。标的数随时间明显增长时，早晚两段不可比，写成限制。

## 十、关于仓位

仓位大小、杠杆、Kelly、止损档位和资金分配属于用户自己的决定，本 Skill 不给。研究里需要仓位时，用固定的、事先写明的研究口径（例如全仓或等权），并在报告里注明它不是建议。
