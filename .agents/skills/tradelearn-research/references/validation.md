# 检验方法：前视、切分、参数曲面、扣除运气与搜索

回测里最常见的错误不是代码写错，而是**在同一份数据上既选参数又评价参数**，以及**把运气当成能力**。这一页给出第 3–5 步的具体做法和公式。TradeLearn 提供切分工具；下面的统计检验用 numpy / scipy 自己算即可，算完把中间量（N、T、偏度、峰度等）写进报告，便于复核。

## 一、前视偏差

**规则**
- 滚动、扩展统计只用到当根之前：`rolling(...).mean().shift(1)` 这类写法；全样本的均值、标准差、分位数都是未来信息。
- 标准化、去极值、特征选择、模型拟合、阈值确定，**只在训练段拟合**，再原样应用到测试段。不要对全样本 `fit_transform`。
- 时间序列不能打乱：交叉验证不用 `shuffle=True` 的 k 折。
- 标签按"收盘到收盘"算、成交却在下一根开盘，这个差距就是隐藏的前视。标签要和实际成交时点一致。
- 基本面、宏观数据按**发布日期**对齐，不按报告期。
- A 股前复权的历史价格包含了后来的除权信息，涉及绝对价位的规则要用不复权价。

**怎么查**
- **截断重算**：把数据截到某个日期重新算信号，截断点之前的信号必须和完整数据算出的完全一致。不一致就有前视。
- **从持仓重建收益**：`收益[t+1] = 持仓[t] × 标的收益[t+1] − 成本 × |持仓[t] − 持仓[t−1]|`，和引擎报告的收益对得上。
- **好得不像真的**：日频简单策略夏普超过 2；样本内外几乎一样好（差距不到 5%）；胜率超过 90% 而回撤很小——这些先当作泄漏或 bug 排查。
- **延迟一根**：把成交整体推后一根 bar。收益大幅消失，说明策略对时点极其敏感，要确认不是用到了当根价格。

## 二、切分

- **训练段**：选参数、拟合模型、调规则、建成本模型、排查 bug。
- **测试段**：只在下结论时**看一次**。看完不满意再改，就需要一段新的测试区间。
- 测试段一般取总长度的 20%–30%，并覆盖一种以上的行情。训练段要足够支撑网格规模：两年日线（约 500 个观测）上扫几十万组参数，等于用 500 个数据点拟合几十万个参数。

```python
from tradelearn.research import time_split

train, test = time_split(bars, split="2023-01-01")   # train < 切分点，test >= 切分点
```

**标签跨期时按真实结束时间剔除**。用"未来 20 天收益"做标签，切分点前 20 天内的训练样本，其标签已经伸进了测试段：

```python
from tradelearn.research.temporal import purged_splits

parts = purged_splits(labels, train_end="2023-01-01", validation_end="2024-01-01")
# labels 需要 forward_return 与 label_end 列；只保留标签在下一段开始前就已结束的样本
```

剔除之外再留一段**间隔**（embargo），吸收剔除后仍然残留的序列相关。常见取值约为标签跨度的 1–2 倍：日线 2–5 根，小时线 6–24 根，1 分钟线 60–240 根。

## 三、有效观测数与显著性

**交易笔数不是信息量。** 在一个构造为零收益、16 个相关标的、持仓 20 天的模拟里，2016 笔交易只相当于约 237 个独立观测，按交易笔数做的 t 检验在名义 5% 的水平下有近一半误报为显著。

- 显著性按**时间段收益**（日收益或策略的自然周期）计算，交易再多也造不出更多的天数。
- 收益序列有自相关时，有效观测数约为 `N / (1 + 2 Σ ρ_k)`（ρ_k 为 k 阶自相关，求和到自相关不再显著为止）；t 值用 Newey-West 等考虑序列相关的标准误。
- 持有 H 期、每期采样的重叠标签，独立观测约为 `N / H`。1000 个日度样本、20 天持有期，只有约 50 个独立点。
- 年化夏普的标准误：`SE(S) ≈ sqrt((1 + S²/2) / T)`，T 为年数。置信区间包含 0，就是"没有显著的净收益"。

## 四、参数曲面与稳定区域

1. **网格**：选承载假设的 1–3 个参数轴；范围放宽到能看见表现下降的边缘。
2. **扫描并记录**：每个组合都计入尝试次数。
3. **平滑**：二维网格取每格与周围 3×3 的平均，一维取相邻几格的平均。
4. **找区域**：保留平滑后指标在 `最优值 − 1 个标准误` 以内的全部组合。
5. **验证区域不是巧合**：在区域内，比较各组合样本内排名与样本外表现的相关性。通常接近 0——这正说明按样本内排名挑选，挑的是噪声。
6. **取整体**：把区域内组合的收益等权平均，作为这套规则的结论。

画参数热力图放进报告：一张热力图比一整张指标表更能说明稳健与否。

**经验警戒线**
- 只在某个精确值上有效（止损 2.13% 有效，2% 和 2.5% 都不行）。
- 换一个时间段，最优参数大幅漂移，或需要频繁重新优化。
- 样本外表现不到样本内的一半。

## 五、扣除尝试次数：紧缩夏普（Deflated Sharpe Ratio）

在 N 次尝试中取最好的一次，即使每次都没有真实收益，最大夏普的期望也明显大于 0。紧缩夏普估计"考虑了尝试次数、样本长度和收益分布形状后，这个夏普仍大于零的概率"。

设：`ŝ` 为所选策略的**每期**夏普（未年化），`T` 为观测期数，`γ3` 为收益偏度，`γ4` 为峰度（正态为 3），`N` 为尝试次数，`V` 为各次尝试每期夏普的方差，`Φ` 为标准正态分布函数。

```
在没有真实收益时，N 次尝试的最大夏普期望约为：
s0 = sqrt(V) × ((1 − 0.5772) × Φ⁻¹(1 − 1/N) + 0.5772 × Φ⁻¹(1 − 1/(N·e)))

紧缩夏普：
DSR = Φ( (ŝ − s0) × sqrt(T − 1) / sqrt(1 − γ3·ŝ + (γ4 − 1)/4 · ŝ²) )
```

- DSR 低于 0.95，说明这个结果很可能来自搜索本身。
- 报告里**原始夏普和紧缩夏普并列**，写明 N。
- 计入的尝试次数只是研究者真实自由度的下限（成本、过滤条件、多空规则的选择也算尝试），所以 DSR 是偏乐观的上界。
- `V` 要从所有尝试的收益矩阵里估；只有被选中的那一条时只能粗估，结果偏宽松，要在报告里说明。
- ŝ 用**每期**夏普，不要代入年化值。

**最短样本长度（MinTRL）**：这个夏普要有多少期观测才在置信水平 1−α 下显著大于目标值 s*（通常取 0）：

```
MinTRL = 1 + (1 − γ3·ŝ + (γ4 − 1)/4 · ŝ²) × (Φ⁻¹(1 − α) / (ŝ − s*))²
```

实际样本 T 小于 MinTRL，就是样本不够，不是策略不行。

**多重检验折扣（Harvey-Liu）**：把年化夏普换成 t 值（约为 `S × sqrt(年数)`）和 p 值，按尝试次数 N 用 Bonferroni（p × N）、Holm 或 BHY 方法调整 p 值，再换回夏普，得到"打折后的夏普"。打折后为负或接近 0，说明没有统计证据。

## 六、回测过拟合概率（PBO）

适用于比较了很多组参数或变体时。做法（组合对称交叉验证，CSCV）：

1. 把整段时间切成 S 个等长的块（例如 S = 16），所有候选组合在每块上都有收益。
2. 枚举所有"取一半块作样本内、另一半作样本外"的组合。
3. 每一种划分下，找出样本内最好的那组参数，看它在样本外的排名百分位 ω。
4. PBO = 样本内最优者在样本外**低于中位数**的划分所占比例。

PBO 高于 0.5，表示过拟合的可能性大于不过拟合。候选组合少于约 10 个时 PBO 意义不大；块数 S 取偶数。

## 七、滚动验证

单次切分只验证了一个时间段。

- **滚动窗口**：训练窗口固定长度、向前滑动，适合认为旧数据参考价值下降的市场（如加密货币）。
- **扩展窗口**：训练起点固定、终点延伸，适合数据较少或行情较稳定时。
- **每一折都重做参数选择流程**（第四节的区域选择），向前带的是区域整体；每折重新挑最优点，验证的是一个你不会使用的流程，结果会偏好。
- 把每一折的样本外结果拼接成一条曲线来看，而不是只看一个总数。各折差异很大，说明依赖特定行情。

## 八、排除"行情"与"运气"

- **对买入持有**：策略收益减去买入持有的差值，检验是否显著；只比较收益率不够，要看风险调整后的差。
- **随机择时**：保持持仓比例和交易次数不变，随机打乱入场时点，重复几百次得到分布。实际结果落在分布的前 5% 以外，才说明择时有信息。
- **蒙特卡洛**：对收益做区块自助抽样（保留短期相关性），得到收益、回撤的分布而不是单个值。估计罕见事件（例如"回撤超过 50% 的概率"）需要上万条路径，路径太少时读出来是 0 并不代表不会发生。
- **历史最大回撤不是风险预算**：它只是一次抽样，通常远小于分布的尾部。用模拟分布的分位数（如 95%）描述回撤风险。

## 九、脆弱性

- **成本压力**：手续费和滑点按 1 倍、2 倍、3 倍各跑一次，并把成本作为一个轴扫描，找出收益归零的**盈亏平衡成本**。盈亏平衡成本离实际成本很近，策略已经不成立。毛收益与成本之比低于约 2.5 倍，余量太薄，经不起估计误差。
- **最差成交**：买在卖一价上方一个最小价位、卖在买一价下方一个最小价位；加入拒单与部分成交。
- **集中度**：去掉收益最高的 5–10 天、去掉最好的一年后还剩多少；逐年列出表现，要求多数年份为正。
- **换标的、换时段**：在几个相近标的、不同子区间上用同一套规则，看是否都成立。只在一个标的、一段四年里存在的收益，描述的是那段时间。
- **容量**：交易规模相对日均成交额较大时，冲击成本随规模非线性上升；估算到多大规模收益会被自身冲击吃光。

## 十、因子检验

**IC**
- 每个截面上，因子值与下一期收益的相关系数；截面因子用秩相关（Rank IC），每个截面单独算，不跨日期混算。
- 报告 IC 的均值、标准差、**IC_IR**（均值 / 标准差）、IC 为正的比例，并画出 IC 随时间的变化。IC 逐年下降，说明因子在被拥挤或行情已变。
- IC 序列有自相关，显著性用 Newey-West 标准误；预测期重叠时按非重叠期计算。
- **样本护栏**：IC 观测少于约 60 期不下结论；少于约 252 期要明确提示样本偏少。
- 量级参考：IC 0.02–0.05 属于中等，0.05–0.10 属于较强，超过 0.10 很少见，先查泄漏。

**衰减与半衰期**
- 对 1、5、10、20 期等不同预测期分别算 IC 均值，看衰减曲线。
- 对 IC 为正的预测期拟合 `IC(h) = A · exp(−h/τ)`，半衰期为 `τ · ln2`。半衰期是对历史形状的拟合，**不是**"还能用多久"的保证。
- 多个预测期的收益常由同一价格滚动生成，彼此高度相关，会扭曲衰减形状，结论里要提示。

**分组与多空**
- 分 5 或 10 组，看收益是否单调；只有头部或尾部一组有效时，写明这一点。
- 多空收益说明理论上的强度，只做多时要单独看多头组相对基准的表现。

**稳定性与换手**
- 因子排名的 1 到 K 期秩自相关，以及它的半衰期：排名越"粘"，换手越低。
- 头部组合相邻两期的重合度（交集 / 并集），可以直接换算成单边换手的近似值；再按调仓间隔和单边成本算出每年的成本拖累，看成本后还剩多少。

**中性化与正交化**
- 先说清要剥离什么：行业、市值、风格、已有因子，不要笼统地说"正交化"。
- **每个交易日单独做截面回归**，在当日可交易的股票里做，不把所有日期混在一起回归。残差就是新因子，重新做截面标准化。
- **绝不能向收益正交**：未来收益、标签、测试段的统计量都不能进入控制变量。
- 正交前后的 IC、收益、换手、覆盖率并列展示。正交后大幅下降，说明原来的收益主要来自已知暴露。

## 十一、数据审计

**行情数据**
- 按交易所日历和时区规范时间戳；检查重复、乱序、缺口。
- 检查价格关系：最高价不低于开、收、最低价，最低价不高于开、收；价格为正，成交量非负。
- 缺口先标为"待核查"：计划休市、停牌、竞价时段不是数据错误，不要直接删或填。
- 只有分钟线时，不能用它推断盘口排队、撤单或逐笔撮合顺序。

**财务数据（时点）**
- 对每个调仓日 T 和每个报告期：只保留在 T 之前已披露的版本，并把披露日顺延到下一个交易日作为可用日（不假设公告当日盘中就能交易），在剩下的版本里取最新的一个。
- **不要用"最新版本"的财报做历史回测**：后来的修订、更正会被提前使用。
- 业绩预告、快报要确认能拿到当时的历史版本，才能纳入。
- 累计值换算成单季、滚动十二个月时，不跨越缺失季度、财年边界或更晚的快照做差分。

**股票池（幸存者偏差）**
- 按历史日期重建每个时点的可选股票池，检查是否有上市前、退市后的标的混入。
- 退市当期的收益要用权威来源给出的退市收益，**不能用 0 代替**；拿不到时写明这是局限。
- 代码变更时，用稳定的证券标识把同一只证券连起来；做不到就说明可能存在偏差。

**期货连续合约**
- 先固定换月规则（按成交量、持仓量还是固定日期），供应商的"主力连续"只是他们的口径，要和你的规则分开报告。
- 识别每次换月及同日新旧合约的价差。连续价格可以做差值或比例调整用来**算信号**；**算盈亏要用真实合约**，换月价差不等于已实现的展期成本。
