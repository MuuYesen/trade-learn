# 样本切分与防过拟合

回测里最常见的错误不是代码写错，而是**在同一份数据上既选参数又评价参数**。这一页讲怎么避免。

## 一、基本切分

- **训练段**：用来选参数、拟合模型、调规则。
- **测试段**：只用来验证，**只看一次**。看过测试段结果再回去改参数，测试段就变成了训练段。
- 切分点之前是训练，之后是测试，**不能打乱时间顺序**。

```python
from tradelearn.research import time_split

train, test = time_split(bars, split="2023-01-01")   # train < 切分点，test >= 切分点
```

测试段一般取总长度的 20%–30%，至少覆盖一段完整的行情环境（上涨、下跌或震荡中的一种以上）。

## 二、标签跨期：要按真实结束时间剔除

如果标签用到了未来数据（例如"未来 20 天收益"），切分点附近的训练样本，其标签会延伸进测试段——训练时已经"看到"了测试期的价格。

```python
from tradelearn.research.temporal import purged_splits

parts = purged_splits(labels, train_end="2023-01-01", validation_end="2024-01-01")
# labels 必须带 label_end 列：每个样本的标签在什么时候结束
# 只有标签在下一段开始前就已结束的样本才会保留
```

预处理（标准化、去极值、特征选择）只在训练段上拟合，再原样应用到测试段。

## 三、滚动验证

单次切分只验证了一个时间段。更可靠的是滚动：

- **滚动窗口**：训练窗口固定长度，向前滑动，每次在紧随其后的一段上测试。
- **扩展窗口**：训练窗口起点固定、终点向前延伸。
- 把每一段的测试结果拼起来看，而不是只看一个总数。各段表现差异很大，说明策略依赖特定行情。

## 四、比较多组参数时的折扣

试了 N 组参数挑出最好的那组，它的样本内夏普一定偏高——其中一部分来自运气。

- 写明一共试了多少组。
- 试得越多，对最优结果越要打折扣；可以用紧缩夏普比率（Deflated Sharpe Ratio）之类的方法估计"考虑尝试次数后还剩多少"。
- 经验警戒线：**样本外表现不到样本内的一半**，或**样本内盈利因子很高而样本外接近 1**，都说明大概率过拟合。

## 五、参数稳定性

- 看最优参数**周围**的结果：附近一片都不错，才可信；只有孤零零一个点好、旁边都差，是噪声。
- 可以画一张参数热力图（例如快线 × 慢线），看是否存在一片稳定区域。
- 优先选稳定区域的中间，而不是表现最好的那个点。

## 六、其他检查

- **分年度**：逐年列出表现，看是否集中在某一两年。
- **换标的**：在几个相近标的上跑同一套参数，看是否都成立。
- **成本敏感性**：把手续费和滑点翻倍，看结论是否还成立。高频、高换手策略对这一项尤其敏感。
- **幸存者偏差**：标的池要包含已经退市或被剔除的标的，否则结果偏高。
